🍽️ | Cardápio Digital de Restaurante |

Este projeto consiste no desenvolvimento de um site de cardápio digital para um restaurante, desenvolvido como parte da disciplina de Frontend e DevOps. O objetivo é aplicar práticas modernas de desenvolvimento web, incluindo estruturação de páginas, estilização responsiva, controle de versões e automação de deploy.

📖 Descrição

O site apresenta um cardápio interativo e responsivo, com categorias como entradas, pratos principais, sobremesas e bebidas. Foi desenvolvido com foco em boa usabilidade, design atrativo e práticas modernas de desenvolvimento frontend.

🛠️ Tecnologias Utilizadas

HTML5

CSS3

JavaScript (puro ou framework como React, se aplicável)

Git e GitHub (versionamento e colaboração)

Ferramentas DevOps:

GitHub Actions (CI/CD)

Deploy automático (ex: Vercel, Netlify ou GitHub Pages)

✨ Funcionalidades

Visualização de categorias de pratos

Informações detalhadas sobre cada item (nome, descrição, preço)

Design responsivo (mobile e desktop)

Navegação intuitiva

Deploy contínuo com GitHub Actions
